- `/style/long-wolf/extra` 等で、404がJavaScript起動後に通常画面へ切り替わる問題を修正。不正URLで保存済み選択を書き換えないようにしました。
- BOOK / MENU / STYLIST / SALONの読込中に案内を表示。画面データ取得失敗時は、保存済み選択を残したまま再読み込みできます。
- 予測先読みの通信失敗が未処理エラーにならないようにしました。
- STYLE未選択でも、選んだ担当・施術・明示選択カラーを予約文へ反映。何も選んでいない場合と明示CONSULTATIONは相談文になります。
- 使われていないThree.js用の旧入口とdrei依存を除去。READMEの「未デプロイ」表記と古いTOP説明を修正しました。

## 性能と確認範囲の限界

- 既存のローカル1回計測ではMobile相当LCP 928ms、CLS 0、操作event duration最大208ms。操作目標200msには未達です。この値は今回の最終版の再計測値や実ユーザーのフィールドINPではありません。
- 公開ドメインの実ユーザーp75・低速実回線・低メモリ実機の性能は未測定です。
- 自動アクセシビリティ検査の違反0は、すべての支援技術やユーザー操作を保証するものではありません。
- 予約URLのクリックと予約確定は別です。予約確定は連携先サービスで行います。

# COLOR IMAGE PROMPTS

COLOR LABの8色×8方向デモ素材は、内蔵imagegenで制作した架空の成人モデルです。生成画像を実在人物の施術例として扱わないでください。

## ベースターンテーブル

```text
Create a premium editorial salon turnaround contact sheet as one exact 4-column by 2-row grid. Use the same fictional adult Japanese male model in every cell, with the same face, layered medium-length wolf cut, neutral expression, bare shoulders, camera height, crop, flat light-gray studio background, soft luxury beauty lighting, and realistic hair detail. Hair color: natural blue-black.

Order the eight views row-major: front, front-right 45 degrees, right profile, back-right 45 degrees, back, back-left 45 degrees, left profile, front-left 45 degrees. Keep the head centered and the apparent scale identical. Every panel must have equal dimensions and clean boundaries. No text, captions, borders, logos, accessories, extra people, duplicate views, dramatic wind, cyberpunk color, or heavy retouching.
```

## 色バリエーション

ベース画像を参照し、各色について次の編集指示を使用します。`[SHADE]` はBLACK / ASH GRAY / SILVER / BLONDE / DARK BROWN / MILK TEA BEIGE / DEEP RED / DUSTY PINKのいずれかです。

```text
Precise object edit of the supplied 4-by-2 turnaround sheet. Change only the model's hair color in all eight panels to [SHADE]. Preserve the exact same fictional adult model, face, skin, hairstyle, strand layout, pose sequence, crop, panel geometry, background, lighting, expression, and resolution. Keep the result photographic, refined, dimensional, and suitable for a luxury Japanese hair salon. Maintain believable roots, highlights, and individual strands. Do not alter facial features, skin tone, clothing, camera angle, spacing, background, or add text, borders, logos, accessories, or extra elements.
```

色間の比較精度を上げるには、将来の正式素材を同一モデル・固定カメラ・固定照明で撮影し、髪領域以外を完全に一致させてください。
